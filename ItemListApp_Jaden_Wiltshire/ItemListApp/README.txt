Jaden Wiltshire — Item Manager assignment

Install: pip install -r requirements.txt
Run: python app.py
Open: http://127.0.0.1:5000

The app starts with three items:
1. computer — $980
2. bookbag — $135
3. Jaden — $42

Screenshot steps (save as JPG):
1. Open homepage before loading items: loadingpage_Wiltshire.jpg
2. Click Load Items: loadeditems_Wiltshire.jpg
3. Click Update on item 2, change its name to Wiltshire, save: updateitem_Wiltshire.jpg
4. Return to homepage and click Load Items: homeupdated_Wiltshire.jpg
5. Click Delete on item 1: deleteditem_Wiltshire.jpg

The data is stored in memory. Restarting the Flask app restores the original three items.
